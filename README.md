# Пока мы взрослеем

Бумажное видеоэссе на две минуты: от детского рисунка дворца до рассвета над городом.

**Смотреть:** https://abubakir128-svg.github.io/poka-my-vzrosleem/

Восемь глав: Детство, Взросление, Люди, Одиночество, Один человек, Дорога, Возвращение, Рассвет.

## Как это сделано

Весь фильм — один файл `index.html`. Каждая сцена нарисована кодом на Canvas и собрана из слоёв «бумаги» с мягкими тенями, а камера движется с параллаксом. Музыка и звуки создаются прямо в браузере через Web Audio API. Видеофайлов, картинок и сторонних библиотек нет.

## Как посмотреть у себя

Скачайте `index.html` и откройте его в браузере.

Управление: пробел — пауза, стрелки — перемотка на 5 секунд, `M` — звук.
